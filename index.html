MaiML

MaiMLは、異なる計測分析装置・ソフトウェア間で データとプロトコルを相互利用するための、 XMLベースの共通データフォーマットです。

Organizations GitHub Repository

About MaiML

MaiML provides a standardized framework for handling analytical and metrological data. The ecosystem is designed to support interoperability, reproducibility, and long-term data utilization across different instruments and software platforms.
