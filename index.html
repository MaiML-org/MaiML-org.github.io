About MaiML

MaiML is a common format for metrological analysis data. It provides a standardized framework for describing analytical and metrological data together with their context, including samples, conditions, workflows, results, and provenance. The MaiML ecosystem supports interoperability, reproducibility, traceability, and long-term data utilization across different instruments, software platforms, and data infrastructures.
