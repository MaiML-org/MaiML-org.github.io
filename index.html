About MaiML

MaiML (Measurement Analysis Instrument Markup Language) is an open XML-based format for describing measurement and analysis workflows together with samples, experimental conditions, results, provenance, and related metadata.

The MaiML ecosystem provides specifications, XML schemas, software libraries, developer tools, and end-user applications to improve interoperability, reproducibility, traceability, and long-term data utilization.
